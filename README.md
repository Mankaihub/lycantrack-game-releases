# Lycantrack Game Releases

Official distribution repository for the Lycantrack game launcher and packaged game updates.

Game downloads will be published as versioned **GitHub Release assets**. This repository does not contain the Unreal project or development source code.

No player release has been published yet. A release will be made available only after installation, update recovery, and game access checks have passed.

The game requires a verified Lycantrack Patreon membership that meets the access requirements, or the verified creator account. Sign-in starts inside the game and uses Patreon's own website.

[Lycantrack on Patreon](https://www.patreon.com/c/lycantrack/membership)

Do not post passwords, access tokens, or other account credentials in issues or comments.
